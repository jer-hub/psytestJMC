# About PsytestJMC

**PsytestJMC** (PSYTEST) is a web platform for student psychological assessment. It helps learners explore career interests, personality traits, and cognitive aptitude, and gives counselors tools to manage tests, organization structure, and analytics.

## Purpose

- Give students a clear path to take **career (RIASEC)**, **personality (Big Five)**, and **IQ** assessments in one place
- Store results securely for review by authorized counseling staff
- Support academic advising with program recommendations and aggregate statistics

## Who it is for

| Audience | How they use PSYTEST |
|----------|----------------------|
| Students | Register, complete a profile, take assessments, view personal results |
| Counselors / staff | Manage questions, users, organization data, and statistics |
| Operators | Deploy with Docker or Vercel and monitor `/health/` |

## Assessments included

1. **Career interest (RIASEC)** — interests mapped to occupational themes  
2. **Personality (Big Five)** — trait profile with optional program recommendation  
3. **IQ** — scored aptitude items (including visual / rich-text questions)

## Built with

Django 4.2, PostgreSQL, Bootstrap, HTMX, Docker Compose, and scikit-learn for recommendation artifacts.
